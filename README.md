# bharti-airtel-equity-dashboard

## 📌 Project Overview

The **Bharti Airtel Equity Research & Financial Intelligence Dashboard** is an interactive web application built using **Python**, **Streamlit**, **Plotly**, and **Yahoo Finance API**. It is designed to provide the data of Bharti airtel by integrating live market data with comprehensive financial analysis.

The dashboard provides insights into Bharti Airtel's financial performance through interactive visualizations, key financial ratios, quarterly results, peer comparison, cash flow analysis, shareholding patterns, SWOT analysis, valuation insights, and an investment thesis. This project demonstrates the practical application of financial analysis, data visualization, and dashboard development in a real-world investment research context.
